How the implied value is built

Every row's value comes from the snapshot's own figures, the same formula for all 200 rows. No protocol name is special-cased.

implied = TVL × category ratio × growth × maturity × breadth

  • Category ratio — the median market-cap / TVL of live-token protocols in the same category (global median when a category has fewer than 3 live ones), clamped to 0.02–1.50.
  • Growth — 1 + 0.6 × the 7-day TVL change, clamped to −50%…+100%.
  • Maturity — 0.70 + 0.30 × age up to 4 years; a protocol listed longer with no token has waited longer for one.
  • Breadth — 1 + 0.05 per extra chain, up to 4 extra chains.
